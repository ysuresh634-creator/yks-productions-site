Questions

Portfolio shoot questions

What is a portfolio shoot in Bangalore?

A paid photography session with me, Yedukrishna Suresh, to make a model or actor book: a planned set of looks, shot and retouched, that you can send to clients and casting directors. It is a YKS Productions photography service. It is not the free YKS Talents portfolio page, which is a website you can build yourself.

How is this different from the free YKS Talents portfolio?

YKS Talents lets models, creators and actors aged 18 to 34 build a portfolio page for free, with no listing fees. This page is for people who want new photographs made: a directed shoot, in Bangalore, with retouching and a finished set. You can use those images on a free YKS Talents page afterwards, or anywhere else you need them.

What does a model portfolio shoot include?

The looks, locations and shot count are agreed in the quote. A typical book needs a clean beauty or digitals-style set plus a few styled looks, with enough range that a client can see how you photograph, not only how you look in one outfit. Digitals can be shot in the same visit if you want both.

How much does a portfolio shoot in Bangalore cost?

I quote one all-in number once I know how many looks you need, whether we are in one location or several, and whether hair and makeup are part of the booking. There is no public rate card, because two books are rarely the same job.

Does booking a portfolio shoot lead to paid modelling work?

No shoot, and no portfolio page, can promise work. A strong book helps a client decide; it does not replace experience. If you also want a free online portfolio to send out, you can apply to YKS Talents after the shoot. YKS Talents is not a jobs board.
